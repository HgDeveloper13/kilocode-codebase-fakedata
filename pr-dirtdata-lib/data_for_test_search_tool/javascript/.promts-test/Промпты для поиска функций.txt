Финальный отчет: Промпты для поиска функций (JavaScript)

1. Файл: utils/userData.js
Этот модуль отвечает за работу с данными пользователя.

Промпт: Найди функцию для загрузки профиля пользователя.
Ожидаемый ответ: Система должна найти функцию loadUserProfile(userId) в файле javascript/utils/userData.js.

Промпт: Найди функцию для сохранения профиля пользователя.
Ожидаемый ответ: Система должна найти функцию saveUserProfile(userId, data) в файле javascript/utils/userData.js.

2. Файл: main.js
Это основной скрипт приложения.

Промпт: Найди функцию для инициализации сессии пользователя.
Ожидаемый ответ: Система должна найти функцию initializeUserSession(userId) в файле javascript/main.js.
