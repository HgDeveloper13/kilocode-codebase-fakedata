# Python Test Project

Полноценный тестовый проект на Python, демонстрирующий различные паттерны программирования, архитектурные решения и лучшие практики разработки.

## 📁 Структура проекта

```
python_test_project/
├── __init__.py          # Инициализация пакета
├── config.py            # Конфигурация и настройки
├── models.py            # Модели данных и бизнес-логика
├── utils.py             # Утилитарные функции и декораторы
├── main.py              # Главное приложение и демонстрация
└── README.md            # Документация проекта
```

## 🏗️ Архитектура и компоненты

### Config Module (`config.py`)
- **AppConfig**: Основной класс конфигурации приложения
- **Настройки базы данных**: Параметры подключения к БД
- **API настройки**: Конфигурация внешних API
- **Константы валидации**: Правила валидации данных
- **Настройки кэширования**: Параметры системы кэширования

### Models Module (`models.py`)
- **Data Classes**: `User`, `Task`, `Project` с валидацией
- **Enums**: `UserRole`, `TaskStatus`, `Priority`
- **Abstract Classes**: `DataRepository`, `NotificationService`, `Validator`
- **Concrete Implementations**: Реализации в памяти для тестирования
- **Exceptions**: Пользовательские исключения проекта
- **Utility Classes**: `ModelFactory`, `DataMapper`

### Utils Module (`utils.py`)
- **Decorators**: `@timing_decorator`, `@retry_decorator`, `@cache_result`, `@singleton`
- **File Utilities**: Работа с файлами, JSON, CSV, хеширование
- **String Utilities**: Обработка текста, извлечение данных, slugify
- **Data Utilities**: Статистика, группировка, обработка данных
- **Validation Utilities**: Валидация email, паролей, UUID
- **Logging Utilities**: Настройка системы логирования

### Main Module (`main.py`)
- **ProjectManager**: Основная бизнес-логика управления проектами
- **DataAnalyzer**: Анализ продуктивности и генерация отчетов
- **Demo Functions**: Функции демонстрации возможностей
- **Performance Testing**: Тестирование производительности

## 🚀 Запуск проекта

```bash
# Переход в директорию проекта
cd data_dirt/python_test_project

# Запуск основного приложения
python main.py
```

## 💡 Ключевые особенности

### Паттерны программирования
- **Singleton**: Декоратор для создания singleton классов
- **Factory**: ModelFactory для создания объектов
- **Repository**: Абстракция доступа к данным
- **Observer**: Система уведомлений
- **Strategy**: Различные стратегии валидации

### Декораторы
- `@timing_decorator` - измерение времени выполнения
- `@retry_decorator` - повторные попытки при ошибках
- `@cache_result` - кэширование результатов
- `@validate_input` - валидация входных параметров

### Обработка данных
- Статистический анализ
- Группировка и агрегация
- Экспорт в JSON/CSV
- Валидация и очистка данных

### Логирование и отладка
- Многоуровневое логирование
- Ротация лог-файлов
- Трассировка выполнения функций
- Обработка исключений
